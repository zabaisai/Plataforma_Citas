Sistema web de gestión de citas

Organiza, agenda y controla tus citas en una sola plataforma.

Plataforma desarrollada en Java con Spring Boot, arquitectura por capas, persistencia con SQLite, APIs internas, manejo de errores y validación de disponibilidad.

POO2 Arquitectura limpia y separación de responsabilidades.
API Endpoints REST para integración del sistema.
SQLite Persistencia portable y lista para despliegue.
